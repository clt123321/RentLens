# 🏠 RentLens（租房透镜） — 租房智能筛选助手

> **告别手动刷房源！** 多平台自动抓取 → 智能筛选 → 通勤计算 → Excel 可视化报告，一站式搞定。

---

## ✨ 为什么需要这个项目？

找房时，你需要同时打开贝壳、自如、安居客、58同城……手动对比价格、面积、通勤时间，效率极低。RentRoom 把这些全部自动化：

- 🔄 **四源并行抓取** — 贝壳、自如、安居客、58同城，一个命令全搞定
- 🎯 **多维度智能筛选** — 预算 / 面积 / 区域 / 地铁站 / 通勤时间，层层过滤
- 🗺️ **通勤精准计算** — 对接高德地图 API，公交+地铁+骑行+电动车，取最优方案
- 📊 **Excel 可视化报告** — 内嵌房源图片、条件格式高亮、筛选报告+流失归因分析
- 🛡️ **反爬策略** — 随机延迟、Cookie 认证、JS 反爬破解、CSS Sprite 价格解码
- 💾 **断点续跑** — Checkpoint 机制，中断后从上次进度恢复，不重复劳动

## 🚀 快速开始

### 1. 环境准备

```bash
git clone https://github.com/clt123321/RentLens.git
cd RentLens

python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. 配置

```bash
cp .env.example .env
```

编辑 `.env`，填入以下信息：

| 变量 | 说明 | 必需？ |
|------|------|--------|
| `BEIKE_COOKIE` | 贝壳/链家登录 Cookie | ✅ |
| `ZIROOM_COOKIE` | 自如登录 Cookie | ✅ |
| `AMAP_API_KEY` | 高德地图 **Web服务** API Key | ✅ |
| `CITY_NAME` | 城市名称，用于地理编码（默认：北京） | ✅ |
| `COMMUTE_DESTINATIONS` | 通勤目标地点（格式见下方） | ✅ |
| `SILICONFLOW_API_KEY` | SiliconFlow API Key（VLM 视觉评分） | ❌ 可选 |

**通勤目标格式**：用 `;` 分隔多个目的地，每个目的地格式为 `名称|完整地址`

```
COMMUTE_DESTINATIONS=公司A|北京市海淀区中关村;公司B|北京市海淀区西二旗
```

**获取 Cookie**：浏览器登录 → F12 开发者工具 → Network → 刷新页面 → 复制请求头中的 Cookie 字段

**获取高德 API Key**：注册 [高德开放平台](https://lbs.amap.com/) → 创建应用 → 添加 **Web服务** Key（注意不是 JS API 类型）。个人开发者每日 5000 次免费额度。

### 3. 运行

```bash
# 一键运行（Windows）
run.bat

# 或手动运行
python main.py

# 自定义参数
python main.py --budget-min 10000 --budget-max 20000 --size-min 40 --size-max 100 --pages 5

# 仅抓取指定平台
python main.py --sources beike ziroom

# 跳过通勤计算（加速运行）
python main.py --no-commute

# 启用 VLM 视觉评分（默认关闭，需配置 SILICONFLOW_API_KEY）
python main.py --enable-vlm

# 断点续跑（中断后从上次进度恢复）
python main.py --resume
```

## 📐 架构设计

```
┌─────────────┐     ┌──────────────┐     ┌───────────────┐     ┌──────────────┐
│  多源爬虫层   │ ──▶ │  筛选过滤层   │ ──▶ │  通勤计算层    │ ──▶ │  报告输出层   │
│  (Scrapers)  │     │  (Filters)   │     │  (Commute)    │     │  (Exporter)  │
└─────────────┘     └──────────────┘     └───────────────┘     └──────────────┘
  贝壳/自如/           预算/面积/           高德API:              Excel:
  安居客/58同城        区域/地铁站          公交+地铁+             图片嵌入+
                                          骑行+电动车            条件格式+
                                                                流失归因
```

### 核心设计理念

1. **漏斗式筛选 + 流失归因** — 每一层筛选都记录数据流失情况，最终生成"流失归因分析"报告，让你知道每条房源为什么被过滤
2. **信源置信度** — 不同平台数据质量不同：贝壳=高、自如=高、安居客=中、58同城=低，在推荐时加权考虑
3. **多模式通勤** — 公交/地铁（高德路线规划）+ 骑行（高德骑行API）+ 电动车（直线距离估算，≤5km），取最短时间
4. **Checkpoint 断点续跑** — 每个阶段完成自动保存，中断后 `--resume` 从断点继续

## 📁 项目结构

```
rentRoom/
├── main.py              # 主入口 & 工作流编排
├── config.py            # 配置参数（从 .env 读取城市、通勤目标等）
├── filters.py           # 筛选逻辑 + 漏斗日志
├── commute.py           # 通勤距离计算（高德地图 API）
├── exporter.py          # Excel 导出（图片嵌入 + 条件格式 + 筛选报告）
├── vlm_scorer.py        # VLM 视觉评分（可选，默认关闭）
├── checkpoint.py        # 断点续跑机制
├── image_utils.py       # 图片下载 & 缓存
├── utils.py             # 通用工具
├── scrapers/
│   ├── __init__.py      # 爬虫注册表
│   ├── beike.py         # 贝壳/链家爬虫
│   ├── anjuke.py        # 安居客爬虫
│   ├── wuba.py          # 58同城爬虫
│   └── ziroom.py        # 自如爬虫（含 JS 反爬破解 + CSS Sprite 价格解码）
├── .env.example         # 环境变量模板
├── .gitignore
├── requirements.txt
└── run.bat              # Windows 一键运行
```

## 📊 输出说明

运行后在 `output/` 目录生成 Excel 文件，包含以下 Sheet：

### 筛选报告
搜索条件、筛选结果统计、推荐标记说明、筛选逻辑说明

### 流失归因分析
每一层筛选的数据流失情况，帮助理解为什么某些房源被过滤

### 数据 Sheet（按来源分）
每个数据源一个 Sheet，包含：

| 列 | 说明 |
|---|---|
| 序号 | 房源编号 |
| 首图 | 房源图片缩略图 |
| 推荐理由 | 自动生成的推荐依据 |
| 房源链接 | 原始房源链接 |
| 房源标题 | 房源标题 |
| 租金(元/月) | 月租金 |
| 面积(㎡) | 房屋面积 |
| 户型 | 房屋户型 |
| 匹配地铁站 | 附近的地铁站 |
| 通勤-目标A | 到目标地点A的通勤时间 |
| 交通方式 | 公交/地铁/骑行/电动车 |
| 通勤-目标B | 到目标地点B的通勤时间 |
| 交通方式 | 公交/地铁/骑行/电动车 |
| 来源 | 数据来源平台 |
| 置信度 | 信源置信度（高/中/低） |

**条件格式**：绿色 ≤20分钟 / 黄色 ≤30分钟 / 红色 >30分钟 / 灰色 需人工核实

## ⚠️ 注意事项

- **Cookie 有效期**：通常数天到数周，过期后需重新获取
- **反爬策略**：程序内置 3-7 秒随机延迟，请勿缩短以免被封号
- **数据真实性**：安居客和 58 同城存在虚假房源可能，请注意甄别
- **API 额度**：高德地图个人认证每日 5000 次，每次运行约消耗 2N 次（N 为筛选后房源数）
- **VLM 费用**：视觉评分使用 SiliconFlow API，约 0.2 元/条
